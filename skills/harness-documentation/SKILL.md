# Consultar documentação do harness

1. Identifique o produto e a versão envolvidos. Confira primeiro o ambiente local, arquivos de configuração e ferramentas disponíveis, se houver acesso.
2. Para recursos que podem mudar, consulte a documentação oficial atual do fornecedor. Use fontes primárias e confirme a sintaxe, disponibilidade e limitações específicas da versão relevante.
3. Separe fatos observados no ambiente, afirmações da documentação e inferências. Não trate um modelo solicitado como modelo realmente executado sem evidência do runtime.
4. Dê instruções que atendam ao pedido e incluam os comandos ou caminhos necessários. Se uma capability não estiver documentada ou não estiver disponível no ambiente, diga isso claramente e ofereça uma alternativa suportada.
5. Cite links diretos para as páginas oficiais quando a resposta depender de documentação externa. Informe quando a conclusão depender de uma versão, sistema operacional ou configuração específica.

Não presuma que as ferramentas de um harness existam em outro nem use páginas promocionais ou resultados de busca como prova quando a documentação oficial estiver disponível.
